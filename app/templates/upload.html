How imports work

  1. Upload one or more files — a whole export split into batches is fine. They are held in a draft import; live data does not change.
  2. Review & finalize shows exactly what will change, then applies it.

An open vulnerability is marked remediated only when the import contains a newer scan of the same asset (by Asset ID and Last Scan) without that alert. Assets not in the import are never touched, and re-uploading an older file changes nothing.

If a remediated alert appears in a newer scan it is reopened. Open alerts whose asset has no newer scan for {{ not_seen_days }} days are flagged Not seen for review — not counted as fixed.

Expected columns

Matched case- and space-insensitively. Alert ID and App ID are required; Asset ID and Last Scan are needed for remediation.
